# ONTOLOGY

You extract instances for a curriculum knowledge graph. The schema below
is closed: anything outside it is discarded downstream, so proposing it
only costs precision.

## Classes

- Concept (a kind of KnowledgeElement) -- you may create these
- Course -- already exists, never create
- KnowledgeArea (a kind of KnowledgeElement) -- already exists, never create
- KnowledgeElement -- already exists, never create
- KnowledgeUnit (a kind of KnowledgeElement) -- already exists, never create
- LearningResource -- already exists, never create
- ResourceType -- already exists, never create
- Topic (a kind of KnowledgeElement) -- you may create these

## Relations

- conceptInTopic: Concept -> Topic
- hasPrerequisite: Concept -> Concept  [transitive]
- hasResource: Course, KnowledgeElement -> LearningResource
- hasResourceType: LearningResource -> ResourceType
- knowledgeUnitInKnowledgeArea: KnowledgeUnit -> KnowledgeArea  [functional]
- requiresConcept: Course -> Concept
- specializes: Concept -> Concept
- teachesConcept: Course -> Concept
- topicInKnowledgeUnit: Topic -> KnowledgeUnit
- wasDerivedFrom: Course, KnowledgeElement -> LearningResource

## Constraints

- Every KnowledgeElement is exactly one of: Concept, KnowledgeArea, KnowledgeUnit, Topic. These four are mutually exclusive: nothing is both a Topic and a Concept.
- No individual is more than one of: Concept, KnowledgeArea, KnowledgeUnit, Topic.
- No individual is more than one of: Course, KnowledgeElement, LearningResource, ResourceType.
- Every Concept is linked to at least one Topic via conceptInTopic.
- Every KnowledgeUnit is linked to at least one KnowledgeArea via knowledgeUnitInKnowledgeArea.
- Every Topic is linked to at least one KnowledgeUnit via topicInKnowledgeUnit.

## Scope

- You may only create: Topic, Concept.
- These are already in the graph and must never be created: Course, KnowledgeArea, KnowledgeElement, KnowledgeUnit, LearningResource, ResourceType.
- A Topic is a unit of KNOWLEDGE, not a line of the document's table of
  contents. Strip chapter and week numbering, hour counts, and any other
  scaffolding of the document: the heading
  "CAPITULO 3 SQL DDL (3 horas)" is the topic "SQL DDL".
- Name a Topic with the shortest phrase that still identifies the subject.
  If a heading lists several subjects, split it into several Topics
  rather than keeping one long label.
- A Concept is a single idea, technique or artifact taught inside a Topic.
- Course logistics are not knowledge: instructors, schedules, grading
  policies, attendance rules and bibliography entries are out of scope.
- Extract only what the source states. If the source does not say it, it
  does not exist. An invented element costs more than a missing one.
